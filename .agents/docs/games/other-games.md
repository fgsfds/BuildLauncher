# Games without an established preparation profile

Read the [common workflow](../addon-conversion-plan.md) and
[manifest specification](../addon.json-Specifications.md). Duke64, DukeZeroHour,
TekWar, Witchaven and Witchaven2 enum recognition does not establish a complete
user-campaign factory, port recipe or packaging capability. Check current code
and actual source resources before preparing them; keep unsupported requirements
unresolved instead of selecting the closest known game's recipe.

RFF entry points remain Blood-only. Do not assume CON support, GRP mounting,
DEF syntax, native map version, palette or artwork style from the Build family
alone. Inventory signatures and dialects, inspect the selected port and obtain a
verified game palette. Start artwork from the game's original branding and author
materials; explicitly record the absence of reviewed same-game examples.
